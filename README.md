# Piezas de GitHub para la elicitación de requisitos (versión interactiva)

Este repositorio ahora incluye una versión interactiva y profesional del documento de la Práctica 7 (Entrevistas, cuestionarios y elicitación de requisitos). La versión interactiva está en:

- docs/index.html — Panel interactivo con los requisitos (issues) extraídos del documento, filtros por tipo y búsqueda.

Qué incluye:
- Requisitos funcionales, no funcionales y defectos extraídos del documento de la práctica.
- Plantilla de issue (archivo en .github/ISSUE_TEMPLATE/requisito.md).
- Guía breve sobre cómo redactar requisitos verificables y trazables.

Sugerencias de uso:
- Abre docs/index.html desde GitHub Pages o en el navegador (ver ruta cruda: https://raw.githubusercontent.com/Fidel20-01/github-pieces/main/docs/index.html).
- Usa la plantilla de issue para cargar cada requisito en GitHub Issues.

Si quieres, puedo también:
- Crear las etiquetas (labels) en el repositorio automáticamente (F, NF, D, Priority:Debe, etc.).
- Crear los issues reales en el repo usando los requisitos listados.
- Publicar la página con GitHub Pages (configuro branch/docs si lo deseas).
