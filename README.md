## Etiquetas

- `F` — Funcional
- `NF` — No funcional
- `D` — Defecto
- `debe` — prioridad alta
- `deberia` — prioridad media
- `podria` — prioridad baja
- `fuente:A1` / `fuente:A2` / `fuente:A3` — origen del requisito

## Plantillas

Este repositorio cuenta con una plantilla para estandarizar la redacción de requisitos.

- [Plantilla de issue](.github/ISSUE_TEMPLATE/requisito.md)

## Documentación del proyecto

La información del proyecto queda en la sección de Issues y en la plantilla del repositorio. El README debe servir como índice y resumen visual, no como texto largo del documento completo.

---

## Resumen

- `Issue` = requisito formal
- `Etiqueta` = clasificación (tipo, prioridad y fuente)
- `Plantilla` = formato obligatorio para escribir igual

Este repositorio está organizado para mostrar la gestión práctica de requisitos en GitHub de manera visual y ordenada.
