# Piezas de GitHub ## Repositorio de requisitos y trazabilidad El proyecto “Libreta Raíz digital” se gestiona aquí como un repositorio de requisitos con trazabilidad real hacia GitHub Issues, prioridades MoSCoW, procesos BPMN y validación con la organización cliente. ### Información clave - Cliente: Panadería “Burritos” - Producto: Libreta Raíz digital - Equipo: ALQF - Documento base: `Practica8.m` - Repositorio: `github-pieces` - Enfoque: gestión de requisitos y documentación del proyecto --- ## 1. Propósito del repositorio Este repositorio cumple tres funciones principales: - servir como registro del DRS y su evolución, - organizar los requisitos en Issues y etiquetas, - mantener una trazabilidad clara desde requerimientos hasta validación. La documentación formal sigue siendo el documento de requisitos del proyecto; GitHub se usa como herramienta de trabajo y seguimiento. --- ## 2. Estructura del repositorio ```text . ├── README.md ├── LICENSE ├── docs/ │ ├── index.html │ └── README.md ├── models/ │ └── README.md ├── evidencias/ │ └── README.md └── .github/ ``` --- ## 3. Alcance ### Fase 1 — lado productor - registro de pedidos, - pago, anticipos y saldos, - seguimiento de entregas, - control de producción por tanda, - registro de mermas, - compras de insumos e inventario. ### Fase 2 — lado comprador - consulta de precio y disponibilidad, - pedido en línea, - confirmación del productor, - punto de entrega, - origen artesanal del producto. --- ## 4.
