Cómo redactar para que sea verificable

- Una sola idea por requisito.
- Verificable: incluye un criterio o medida (ej. "Se completa en máximo 3 pantallas").
- Trazable: indica la fuente (p. ej. A1, A2, P18).

Funcional / No funcional

Funcional
Qué debe hacer el sistema. Se verifica con una prueba: ¿lo hace o no?
No funcional
Qué tan bien lo hace. Debe incluir medida: tiempo, tamaño, porcentaje.
