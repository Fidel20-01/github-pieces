# Evidencias y validación

Esta carpeta debe contener la documentación de validación con la organización y evidencias de campo.

## Contenido sugerido

- acta de validación del DRS,
- bitácoras de entrevistas,
- fotografías o capturas de prototipo,
- transcripciones de reuniones,
- registro de cambios entre versiones.

## Recomendación

Guardar aquí:

- actas de revisión,
- evidencias de validación,
- registros de decisiones del cliente,
- historial de cambios y ajustes del documento.
